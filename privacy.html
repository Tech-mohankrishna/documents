Privacy Policy

Mythology Pipeline · last updated 22 November 2026

What this application is

Mythology Pipeline is a private, single-user tool that publishes short videos to one YouTube channel owned and operated by its author. It is not offered to the public, has no sign-up, and has no users other than its author.

What data it accesses

The application uses the YouTube Data API v3 with the author's own Google account, under these scopes:

  • youtube.upload — to upload a video file
  • youtube.force-ssl — to set a thumbnail, attach a caption track, and set a scheduled publication time on the videos it uploads

It reads the authenticated channel's name and ID once, at setup, solely to confirm it is connected to the intended channel.

What data it collects, stores or shares

None from any third party. The application has no users besides its author, collects no personal information from anyone, and operates no server, database or analytics.

An OAuth refresh token is stored in a local file on the author's own computer so the tool can upload without re-authenticating each time. That file is excluded from version control. The token is never transmitted anywhere other than to Google, and is never shared with any third party.

Third-party services

Video and audio are produced locally. Narration is synthesised using ElevenLabs. Finished videos are uploaded to YouTube. No viewer or visitor data is processed by this application at any point.

Data retention and removal

Access can be withdrawn at any time by the author at myaccount.google.com/permissions, which immediately invalidates the stored token. Deleting the local environment file removes every stored credential.

Children

The application is a developer tool and is not directed at children.
